## 3. Evaluation power tolerance: NONE, confirmed in writing
The registration (experiments/w5_governor.yaml) defines the budget as "mean GPU board power over the 60 s measured window (NVML energy counter / time)" and a feasible cell as "miss fraction <= 1% AND mean power <= budget". There is NO tolerance: a cell is feasible only if its counter power over the window is <= 60.0 W (<= 35.0 W for the exploratory budget), and an infeasible cell scores 0. The cell power of the analysis is the counter's start/end value (power_w in cell.json, as in W5a and the tuning blocks); the Governor's own signal is the sampled mean (O-5), which agrees with it within 2.9% in T3b. Consequence stated before block 1: d'B sits at 58.1-59.9 W in T3b (the ModelController aims at 97% of the budget, 58.2 W), so some evaluation cells may land just above 60.0 W and score 0; that is registered behaviour and is not adjusted.

## 5. Evaluation protocol details fixed before block 1 (experiments/w5b/evaluate.py)
Blocks 4-13 (10 evaluation blocks); one block = 25 primary cells (scenes S0, S1, S1d, S2, S5 x controllers g'B, eB, c'B, d'B at 60 W + the reference arm a in the 5 scenes); blocks 4-8 add the exploratory 35 W family (the same 20 cells; no arm a); S3 (thermal cap emulated through the helper allowlist) is NOT built and not run (exploratory); d'B-HGB is NOT built. Background: the 3B for S0, S1, S1d, S2; the held-out Llama-3.1-8B (never used before) for S5. Foreground: synthetic FMA at nominal c0 = 7 ms. SCENE TIME starts at the beginning of the 60 s MEASURED window (the 5 s warm-up runs at the scene's t = 0 conditions): S1 steps x1.0 / 0.7 / 1.3 / 0.7 / 1.0 / 1.3 every 10 s; S1d linear 0.7 -> 1.3 over the window; S2 active 0-20 s, idle 20-30 s, active 30-50 s, idle 50-60 s. (The tuning cells used scene time from the start of the 65 s loop; the evaluation cells use the window, which is what the registration describes.) Controllers: g'B = the frozen static setting per budget; eB = the g'B setting plus the idle drop to the knee clock (IdleDropController); c'B = SwitchingPIController with the frozen constants; d'B = the hybrid with the frozen margin; all governed cells use the SAMPLED power source and read the energy counter zero times (O-5). Frozen constants: data/w5b/constants.json (built by experiments/w5b/freeze.py from the tuning decisions, committed, its sha256 passed on the command line like the W5a list). Cell order inside a block is seeded-random per (block, cell); 20 s minimum cool-down and below 55 C before each cell with the clock unlocked; sessions of at most 3 h (the runner refuses a request whose estimate, 100 s per cell, exceeds it), a fresh restart before every session (uptime <= 2 h), blocks never split; a block interrupted by an abort is discarded whole (kept, marked) and rerun with the same seed list under the next block number (`--as-block`). Output: one results table with the columns of analysis/w5_analysis.py.
