## 2. c'B fallback (decided after T3c)
RULE. The registered fallback (lowest mean miss when no combination meets mean miss <= 1% and mean power <= 60 W) picked target 0.2, ki 0.15 (mean miss 3.08%, 0.6 tok/s, 24.4 W): a comparator that barely runs the background. O-7 replaces the fallback by: among the combinations with mean power <= the budget whose mean miss is within d of the lowest such mean miss, the highest mean tok/s (ties: lower target, lower ki). The rule when the miss rule IS met is unchanged. Code: tune_lib.pick_cb_o7, applied by freeze.py.
TOLERANCE d, from existing replicate pairs only (code: experiments/w5b/o7.py, output data/w5b/o7_tolerance.json). FORMULA: d = percentile95(|miss_a - miss_b| over the pairs) / sqrt(6) (linear interpolation; the sqrt(6) scales a per-cell difference to a difference of two 6-cell means, assuming independent per-cell noise). PAIRS (fixed by the code's definition before the pick was applied; same spec, cells of the final controller code on the sampled source, in different directories among diag, T3b, T3c; discards and energy-source cells excluded): 7 pairs.
- 1 strict replicate: c'B 3B S1 t0.5 ki0.15: diag_cb_sampled 6.33% vs cb2_llama32_3b_S1_t0.5_k0.15 6.58% (|diff| 0.250 points).
- 6 near replicates: d'B at margin 0.3, each of the 6 workload / scene cells, T3b db_* vs T3c dbh_*. They differ in the steering budget (the headroom), so each difference contains that perturbation (it can only widen d): 1B S0 0, 1B S1 0, 3B S0 0, 3B S1 2.00% vs 1.92% (0.083 points), Phi S0 0, Phi S1 3.25% vs 3.25% (0).
NUMBER. p95 of |diff| = 0.200 points; d = 0.200 / sqrt(6) = 0.0816 points (0.000816).
RESULT. Within 0.0816 points of the lowest mean miss (3.083%) there is no other combination (the next ones: t0.35 ki0.15 +0.134 points, t0.5 ki0.15 +0.213, t0.65 ki0.15 +1.394). The O-7 pick is therefore the SAME as the registered pick: target 0.2, ki 0.15. The rule as specified does not change the comparator. Reported both ways: O-7 pick = registered pick (identical, so no separate registered-sensitivity run exists to label; the frozen constants carry c_b_registered with that status).
SENSITIVITY (not used). Strict pair only (n = 1): d = 0.102 points -> same pick. Only the 3 pairs with any miss > 0: d = 0.095 points -> same pick. d needed to move the pick: >= 0.134 points -> t0.35 ki0.15 (13.6 tok/s); >= 0.213 -> t0.5 ki0.15 (17.3 tok/s, 3.30% miss); >= 1.394 -> t0.65 ki0.15 (27.0 tok/s, 4.48% miss).
LIMITS, stated. (1) The c'B noise rests on ONE pair (0.25 points per cell): a percentile of 7 pairs, six of which are d'B near replicates with many floor cells (miss 0 in both runs), is a weak estimate and probably too small for c'B. (2) Independence across cells is assumed. (3) The c'B comparator therefore remains the degenerate "lowest-miss" setting (24 W, 0.6 tok/s): any d'B-versus-c'B non-inferiority statement against it is close to vacuous and the paper must say so. Whether to replace d by a better estimate (for example 12 c'B replicate cells, about 20 minutes) or to add an extra comparator setting (for example t0.5 ki0.15) as an exploratory arm is Arjun's decision; neither is done here. No further tuning of d.

FROZEN: 2.692 W (steering target 57.308 W at 60 W; parameter (60 - 2.692) / 0.97 = 59.080 W; 33.307 W at 35 W).

The frozen value was not run itself; the difference is small and in the conservative direction (a lower steering target); reported, no re-run. The T3c decisions.json is left unchanged (data); the constants file records both numbers (headroom.w and rules.d_b_headroom_ran_with_w).
