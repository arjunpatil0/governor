# ADDENDUM O-5 — POST HOC: the diagnostic gate said STOP on magnitude only; the sampled power source is adopted anyway (written 2026-10-24, after the diagnostic, BEFORE T3b and before any evaluation block)
This note is POST HOC with respect to addendum O-4: O-4 was registered before the diagnostic; the decision below is made after seeing its result and is labelled accordingly. The gate output (data/w5b/diag/*, power_source.json) is NOT edited: the verdict stays STOP, exactly as computed.

## 1. The gate verdict as computed (data/w5b/diag, power_source.json: power_source null, verdict STOP)
Cells (3B, S1, c0 = 7; counter power | sampled mean | Governor energy reads/s | tok/s): diag_static 41.1 | 39.7 | 0 | 19.9; diag_gov_static 114.3 | 39.6 | 10.02 | 20.0; diag_gov_static_noenergy 40.6 | 39.9 | 0 | 20.0; diag_cb 58.6 | 31.8 | 10.02 | 5.7; diag_cb_sampled 37.0 | 37.0 | 0 | 12.7 (miss 6%).
Reasons printed by the gate: "diag_gov_static: inflation +73.2 W (counter - static) / +74.7 W (counter - sampled) does not match the prediction 42.1 W"; "diag_cb: inflation +26.8 W does not match the prediction 42.1 W". No other check failed.
PREDICTIONS THAT HELD (qualitative, all pre-registered in O-4): (1) the counter is inflated ONLY on the arms whose Governor loop reads the counter (+74.7 W, +26.8 W); the static arm and the no-reads arm are not; (2) the independent sampled power is identical across static / Governor / no-reads (39.7 / 39.6 / 39.9 W): the load is not real; (3) throughput is identical across static / Governor / no-reads (19.9 / 20.0 / 20.0 tok/s); (4) the fix arm's counter equals its sampled power (+0.0 W) and c'B's throughput rises from 5.7 to 12.7 tok/s: the phantom power starved the background.
PREDICTION THAT FAILED: the MAGNITUDE. The gate assumed 4.2 J per read (journal 0005); the implied figure is 74.7 W / 10.02 reads/s = 7.5 J per read in the g'B state and 26.8 / 10.02 = 2.7 J per read in the c'B state. The per-read phantom energy is STATE-DEPENDENT (journal 0005 already noted a state-dependent offset); the fixed constant was my assumption, not a measured law.

## 2. Decision (post hoc): power_source = 'sampled' for T3b AND for every evaluation block
Justified only by the predictions that held. The sampled source never reads the energy counter in the Governor loop, so the per-read magnitude is irrelevant to it; it was validated on the diagnostic by the fix arm (counter = sampled). It is NOT justified by the failed magnitude prediction, which is reported as failed. Rules that follow: (a) `tune.py --plan t3b` takes an EXPLICIT `--power-source sampled`; with 'auto' and a STOP verdict it stays refused; an explicit 'energy' for T3b is refused while this note exists; (b) every governed T3b and evaluation cell (c'B, d'B, d'B-HGB, any controller run through the Governor loop) uses the sampled source: the loop reads the energy counter zero times, only the two window reads (start / end) remain, so the cell's counter power and its sampled power stay comparable; the executor rejects a sampled-source cell whose loop read the counter, the default source of the hardware executor is 'sampled', and the morning check FAILS any non-diagnostic cell whose `gov_reads` is above 0 and any cell whose counter and sampled power differ by more than 15%; (c) the evaluation runner (not yet written) must construct its executor with power_source = 'sampled' and is tested for it.
Consequences recorded: the 4.2 J per read figure is state-dependent and is used nowhere as a constant of the study except as the (failed) prediction of O-4; wherever it appears (journal 0005 note, CONCEPTS, PAPER_MAP, the gate's comment) it carries the 2.7-7.5 J range. The c'B constants of the T1-T3 sitting stay void; the fix arm shows c'B regains 12.7 tok/s but at 6% miss with the diagnostic constants (target 0.5, ki 0.15): the c'B grid of T3b is where that is tuned, not a result of the diagnostic.
