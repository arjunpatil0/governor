## 2. Clock clamp (reviewer note 1)
The live SM clock is clamped into the measured model range [600, 2460] MHz before any controller sees it (Params.clamp_clock; Governor.step), every clamp is logged (Governor.clamped; cell.json `clamp_events`, `clamp_examples`; the morning check prints the total), and the unlocked GPU's 2475 MHz reading maps to the top of the range. Every live-clock path into the model tables goes through Governor.step (controllers/model.py, controllers/pi.py, controllers/tokmodel.py read obs.clock_mhz only); tested with 2475, 2460, 1800 and 210 MHz readings on c'B (aligned and unaligned) and d'B (tests/test_clock_clamp.py).

## 3. One action space for every controller (reviewer note 2, blocker)
The shared action space is clock x {aligned guard/duty, unaligned duty}. g'B, eB and the statics: the full space (the 70 settings). c'B (PIController): implements both modes; its mode is fixed PER CELL by the measured c0m (aligned if c0m <= 6.57 ms, else unaligned, addendum O section 4): same space, but c'B cannot switch inside a cell (the yaml's "falls back to unaligned when the aligned slack cannot hold a token" is applied once per cell). At the trial's c0m = 6.68 ms c'B would run unaligned. d'B (HybridController) was aligned-only and delivered 0 tok/s when no token fits the slack; it now keeps an aligned and an unaligned ModelController, chooses the executed mode on the slow loop (every 1 s) by the predicted token rate of the two plans with hysteresis (the other mode must predict more than 1.2 x + 2 tok/s for 2 consecutive checks), cuts the cross-contamination of the two models (tests/test_hybrid_dual.py, controllers/hybrid.py), and keeps the idle branch (eB rule) unchanged. d'B-HGB (addendum O section 3) must be built on this hybrid and share the same space. Known limitation: the unaligned instance predicts tokens from the L table (3B) and learns only the frame cost, the interference factor and the power bias online.
Unit-test evidence on the FROZEN simulator (a test harness, not an evaluation): at frame cost 10 ms the old aligned-only hybrid made 0 tok/s; the new one makes 12 tok/s with miss 6.2% at margin 0.2 and 5 tok/s with miss 2.3% at margin 0.4 - the unaligned plan is optimistic and the margin is the knob block T3b tunes.
