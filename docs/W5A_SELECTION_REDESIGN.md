Decision: Option A with five conditions (reviews/2026-10-23_w5a_selection_result_review.md; Arjun + reviewer). Run 1 (commit 00d68e8, data/w5a/selection.*) stays as the record of the registered protocol: nothing selected. The re-run is POST HOC (designed after seeing run 1's failures and data shape), is the ONLY one, and uses the same 280 cells, the same folds and the same adaptation rule (addendum L section 3, K = 3 primary, K = 1 sensitivity). It touches nothing of the confirmatory W5b test (held-out 8B and the fresh evaluation blocks). No third round.

## 1. Run 1's unregistered deviations — each adopted or reverted (run 1's report is amended to say they were unregistered)
Introduced during implementation of run 1 without sign-off: (1) intervals = RMS of inner out-of-fold residuals -> REVERTED (replaced by cross-conformal intervals, section 3). (2) GP = subset-of-data (at most 150 cells, rng seed 0) instead of inducing points -> ADOPTED as the registered GP (a subset-of-data sparse approximation; with about 190 training cells it is close to the full GP; the seed is fixed at 0). (3) predicted-overload p99 := 16.667 ms -> ADOPTED for FEATURE construction only (the predicted p99 of G is an input of the learned models); p99 is no longer a scored decision target. (4) CUSUM change detector not evaluated offline -> ADOPTED: it is an online-loop component with no cell-level meaning; plan B's per-candidate CUSUM is evaluated in W5b, not here. (5) REGRET_REL margin absolute +0.10 instead of a ratio -> ADOPTED (a ratio rule is degenerate near 0), with regret computed on the strata that have an observed-feasible candidate only (section 5).

## 2. Targets (what the controller decides on)
Observed per cell: feasible = `miss_frac_incl_abandoned` <= 0.01; active = `bg_tokens` > 0; log tok/s = ln(`bg_tok_s`) on active cells; power = `power_w`; in-range p99 = `fg_p99_ms` on non-overloaded cells whose p99 <= 100 ms (the backlog tail carries no decision information: seconds of p99 = infeasible).
T1 FEASIBILITY CLASSIFIER p_feas = P(feasible). Controller threshold tau = 0.8 (fixed now: a missed deadline is worse than a missed opportunity); also reported at 0.5. Scored at tau: FALSE-FEASIBLE rate (predicted p_feas >= tau, observed infeasible; share of predicted-feasible cells; with exact binomial CI) and FALSE-INFEASIBLE rate (predicted < tau, observed feasible; share of observed-feasible cells).
T2 two-part tok/s: p_act = P(active) (classification at 0.5, reported) and mu = ln tok/s given active (MAE in ln units = relative error; reported also as median relative error).
T3 power: MAE in W; classification at 60 W reported.
T4 in-range p99: MAE on cells in range, SECONDARY, reported only (no gate).
G (grey-box): p_feas = 1[predicted miss <= 0.01], p_act = 1[predicted tok/s > 0], mu = ln max(predicted tok/s, 0.1), power, p99 as in addendum L. Learned candidates (HGB, GP, MLP as in addendum L section 4, hyper-parameters unchanged) learn the RESIDUALS y - G for the indicators p_feas, p_act (clipped to [0, 1] after adding G), mu (active cells only), power and in-range p99, with the same shrunk online residual (n/(n+1) mean over the K adaptation cells) for mu, power and p99 (none for the two indicators).

## 3. Intervals: cross-conformal, transformed space, per fold
For mu (natural log of tok/s) and power (W): within each outer fold, the training workloads' inner leave-one-workload-out out-of-fold absolute residuals s_i = |t(y_i) - t(yhat_i)| are pooled (n scores; same calibration and bias as in the outer fold); q = the ceil((n+1) * 0.95)-th smallest score (the largest if that rank exceeds n); interval = t^-1(t(yhat) +/- q) (tok/s interval = [exp(mu - q), exp(mu + q)]). Coverage is the share of observed values inside, pooled over the LOWO test cells (tok/s on observed-active cells, power on all cells); gate 90-98% unchanged. This replaces run 1's RMS intervals.

## 4. Latency: a changed requirement, declared with its rationale
Run 1: predict + decide < 1 ms p99 for the 70 settings (a per-frame budget). The clock/pacing decision is made in the SLOW loop (0.5-1 s period; plan, ADR), so the real requirement is one batched predict over the 70-setting grid per decision: p99 <= 10 ms (1% of the shortest slow-loop period). The per-frame fast loop (token release, learned guard) NEVER calls the heavy model. Measurement: the real batched decide path (features, all five residual models, conformal margins, the decision rule), 70 settings, p99 over 300 repetitions after 50 warm-ups, with the numeric thread pools limited to 1 thread (threadpoolctl; the controller process must not compete with the workloads for cores; declared here, not chosen after the result). Every candidate is reported against BOTH 1 ms and 10 ms, and also with default threads; the gate is the 10 ms bound with 1 thread.

## 5. Decision metrics
Per held-out stratum (workload x condition) among the stratum's test cells: pick = argmax exp(mu) over cells with p_feas >= tau, p_act >= 0.5, exp(mu) >= 1 tok/s and power + q_power <= 60 W; none otherwise. Observed feasible = feasible and `power_w` <= 60; best = max observed tok/s among observed-feasible cells (0 if < 1 tok/s). REGRET (the full best if the pick is observed-infeasible or absent; best - observed tok/s otherwise) and REGRET_REL = sum regret / sum best are computed ONLY over strata with best > 0 (run 1: 8 of 18; the count is reported; the heavy conditions are often entirely infeasible at 60 Hz, a property of the plant). FALSE-FEASIBLE PICK RATE = false-feasible picks / picks, with the exact 95% Clopper-Pearson interval, and the number of picks.

## 6. Gates and selection rule
Hard gates (K = 3, pooled LOWO): G1a false-feasible rate of predicted-feasible cells at tau <= 5%; G1b false-feasible pick rate <= 5% (point estimate; the CI is reported; with few picks one failure fails); G2 conformal coverage 90-98% for mu and power; G3 latency p99 <= 10 ms (section 4). Among passing candidates: qualifies if mu-MAE <= 1.10 x best, power MAE <= 1.10 x best, false-infeasible rate <= best + 0.10 (absolute) and REGRET_REL <= best + 0.10 (absolute); the simplest qualifying candidate (G < HGB < GP < MLP) is selected.
