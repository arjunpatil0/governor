# ADR-0007 — Implementer/reviewer split via files in reviews/
Status: accepted · Date: 2026-10-20
## Context
Two Claude sessions cannot message each other; Arjun relays decisions.
## Options considered
(a) Arjun copy-pastes everything; (b) shared-repo review files with response files
## Decision
(b)
## Rationale
Asynchronous, auditable, minimal relaying; Arjun arbitrates disagreements.
## Evidence
CLAUDE.md review protocol.
