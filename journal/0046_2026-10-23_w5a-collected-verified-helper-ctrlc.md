**Helper shutdown (actuators/clock_helper.py).** Before: the Ctrl+C handler ran the whole cleanup inside the console-control callback and then called os._exit, and `PipeServer.stop()` only woke a server that was waiting for a client (a throwaway connection); a server blocked in ReadFile on a connected client was woken only by the 10 s idle monitor. After (7 new tests in tests/test_clock_helper.py, RED first on the missing names, then GREEN; 52 passed, 1 skipped): the handler only sets a stop event and returns "handled" at once; the main thread stops the server by repeated CancelIoEx until the serving thread has left (both when waiting for a client and when blocked on a silent connected client), then runs the cleanup once, prints "shutting down... clock reset done" (or "...FAILED (see the helper log; run nvidia-smi -rgc)"); a second Ctrl+C / Ctrl+Break during the cleanup is swallowed; close, logoff and shutdown events block until the cleanup finished (Windows ends the process when the handler returns); atexit and finally call the same once-only cleanup.
