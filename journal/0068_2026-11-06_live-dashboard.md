Found on the way (all fixed, tests added):
1. The reference page's canvas grew every frame whenever devicePixelRatio is not 1 (setupCanvas read the height from an attribute it then rewrote); this browser runs at 1.25, the stage grew to 26 million px. Fixed in the build by keeping the base height in a data attribute (reference file untouched).
2. On Windows SO_REUSEADDR let two dashboard servers answer on the same port; now bound exclusively (test: a second server cannot share the port).
3. NVML nvmlDeviceGetPowerUsage on this laptop returns 590006 mW for a few samples (seen 2 of 5 direct reads while idle, with Chrome open): dropped above 250 W and counted. The project's own samplers do not filter this; the registered power_sampled_w means (about 57 W) show it was not a problem in the evaluation cells, but I did not check how often it occurs there. Not investigated further.
4. NVML calls inside the stream loop halved the live message rate to 9/s; polling now runs in a thread (19.9/s).
5. The decision log in recorded evaluation cells has no predictions (only the 10 Hz commanded settings): REPLAY of those shows the commanded settings and says the reasoning was not recorded; only demo cells keep it.
