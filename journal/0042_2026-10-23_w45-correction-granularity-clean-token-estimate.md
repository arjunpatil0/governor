**2. Granularity finding (recorded).** A clean 3B token takes 10.1 ms. The slack after a frame is period minus the frame time = 16.67 - c (about 16.67 - 6.8 at c0 = 7 ms measured, 6.78 ms median latency). A token fits the slack only if c <= 16.67 - 10.1 = 6.57 ms, so at c0 >= about 6.6 ms the slack is shorter than one token: aligned pacing admits no whole token. Below that, slack holds at most one token (two need 20.2 ms), so aligned pacing is capped at one token per frame = 60 tok/s at 60 Hz (the 59.7-60.0 tok/s of smoke 2 equals this cap, by coincidence of the bug starting one token per frame). At light frames aligned is capped at about 60 tok/s while the background alone does 100 tok/s; at heavier frames it admits about none, and the controller must choose unaligned (duty-cycle) pacing there, accepting overlap (token 2.05x, frame 1.95x, fg tolerated it at 7 ms). Derived from measured values; the boundary itself is not measured (smoke 3 measures costs 4 / 7 / 9 ms). STATED LIMITATION: sub-token (layer-level) pacing, which would let the background yield inside a token, is future work.
